WinBridge 快速使用说明

1. 安装完成后，在 Windows 系统托盘中找到 WinBridge 图标。
2. 双击图标或右键选择“编辑配置…”。
3. 将 winbridge.json 中的 change-me 替换为一个较长的随机令牌。
4. 将 Windows 的局域网 IP 和同一个令牌填入 MacBridge 配置。
5. 右键托盘图标，选择“重新启动服务”。
6. Windows 弹出防火墙提示时，只允许其通过专用网络。

托盘菜单会显示监听、连接和认证状态。WinBridge 安装后自动启动，并在用户登录时自动启动。需要停止服务时，请从托盘菜单选择“退出 WinBridge”。
